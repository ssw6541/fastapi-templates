# 마켓노트

네이버 증권의 국내 지수와 주요 종목 시세를 확인하는 FastAPI 대시보드입니다.

## 실행

프로젝트 폴더의 VS Code 터미널에서:

```bash
uv sync
uv run uvicorn main:app --reload
```

브라우저에서 http://127.0.0.1:8000/ 을 엽니다. 기존 `/tomato` 주소도 같은 화면을 표시합니다.

## 기능과 데이터

- 코스피·코스닥 지수 및 국내 대표 종목 20개의 현재가, 전일 대비, 등락률, 거래량
- 종목명·코드 검색, 시장별 필터, 수동 새로고침 및 60초 자동 갱신
- 서버에서 네이버 시세를 가져와 30초 동안 재사용합니다. 표시 시간은 제공처가 반환한 시간입니다.
- 네이버 제공 데이터는 지연될 수 있으며, 제공처의 형식이나 정책이 바뀌면 수집이 중단될 수 있습니다.
- 종목 목록은 `main.py`의 `STOCKS`에서 변경할 수 있습니다.

테스트: `uv run python -m unittest test_market`
